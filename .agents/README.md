# `.agents/` Rule Layers

- `shared/`: universal authority, safety, validation, context, delegation
- `domains/`: department responsibilities
- `stacks/`: framework/language engineering rules
- `concerns/`: task-selective risk areas
- `runtimes/`: Grok vs Cursor execution behavior

`AGENTS.md` in each repository is the router and repository-specific contract.

Avoid duplicating generic rules into repository profiles unless intentionally overriding them.
